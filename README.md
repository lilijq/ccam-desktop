# CCAM Desktop

**面向 Claude Code 与 CCAM 的原生 macOS 工作台。** 在一个窗口中并排推进多段对话，查看文件与 Git，使用终端和共享代理网页；中文输入与英文回复可在本机翻译。

**项目保存任务与上下文，账号管理额度。** 多个项目共用账号池；额度中断时，工作台通过 CCAM 的恢复票据换号续接原会话。

A native macOS workspace for CCAM and Claude Code: split conversations, account usage and session handoff, files, Git, terminal, a shared-proxy browser with MCP, and on-device Chinese–English translation.

当前源码版本 **2.13.1** · Swift / AppKit · [MIT](LICENSE)

## 能做什么

| 工作对象 | 功能 |
| --- | --- |
| 账号与额度 | 查看各账号额度与状态，添加、登录和管理账号；订阅账号组成全局池，项目不绑定固定额度。 |
| 多对话 | 同一项目的不同对话可并排推进，草稿、附件、模型、思考强度与权限模式独立；执行过程默认折叠，回复渲染 Markdown。 |
| 连续任务 | 额度中断后通过原会话和中断票据换号续做，保留目录与上下文；网络或登录错误不会自动换号。 |
| 本机翻译 | Hy-MT2 技术翻译模型在 Apple Silicon 上原生运行；输入可转为英文、回复按句段自动显示中文，代码和免译内容保持原样，支持复制原文。 |
| Chrome 个人资料 | 为 CCAM 账号选择登录时使用的 Chrome 个人资料，可自由搭配、修改或解除绑定。 |
| 项目 | 添加文件夹、切换、重命名、归档和恢复。同一项目的多个对话与文件、Git、终端、网页可左右或上下分屏；切换项目或隐藏窗格不会停止后台任务。 |
| 文件 | 可展开目录树、文件图标、多文件标签、代码语法高亮、行号和查找；编辑 UTF-8 文本并保存，检测外部修改以防覆盖冲突。 |
| Git | 查看分支、改动和差异，按文件暂存或取消暂存，再提交已暂存改动。 |
| 终端 | 内置交互任务与开发终端；需要进一步交互时，可把图形对话移交到原会话的终端。 |
| 网页 | 原生内嵌浏览器，按项目保存标签；与对话共用分屏，通过本机 MCP 操作同一个页面，沿用全局代理。需要 macOS 14+。 |
| 功能中心 | 7 类功能与搜索，提供 61 项可视化操作，覆盖适配版本的 67 项底层操作。 |

窗口使用中性黑、轻量面板标题、图标工具栏和细边界，也支持浅色和跟随系统。左侧可以收成图标栏，保留项目、额度与设置入口；顶部空白处可以拖动主窗口。项目与对话保留在侧栏；账号、额度、外观和设置收进左下角齿轮。日常管理通过按钮完成，无需输入 CCAM 命令。

## 网页与 Claude 协作

![对话与网页分屏（离线验收）](docs/images/web-chat-split-desktop.png)

顶部“网页”默认在对话右侧打开内嵌浏览器，分屏菜单可以将它放在其他位置。支持地址栏、标签、前进后退、刷新和停止加载；最多保存 8 个标签，同时显示最多 4 个工作区窗格。项目切换会保留页面状态，重启后需要点击刷新恢复已保存地址。

浏览器使用全局代理设置（可在左下角设置或网页代理状态按钮修改），通过 WebKit 显式配置 HTTP CONNECT 代理并关闭直连回退。非 localhost 导航前还会检查代理端口是否可连接；端口不通立即停止加载。聊天继续通过同一配置设置 HTTP_PROXY / HTTPS_PROXY；更改设置会停止网页加载，已运行的 Claude 进程在下一轮启动时采用新配置。localhost、127.0.0.1、::1 保留本地开发访问。内嵌网页不导入 Chrome 的 Cookie 或账号。

图形对话启动时自动接入本机 `ccam-web` MCP：标签列表、打开/切换/关闭标签、页面快照、点击、输入、滚动与截图。工具使用项目自己的浏览器实例，授权沿用现有项目权限；网页右侧“Claude 可用”可随时停用。已启动的对话需要在本次更新后重新启动下一轮，才能获得新工具。

当前为基础网页能力：元素操作针对主文档，跨域 iframe、下载和文件上传尚未接入；没有任意 JavaScript 执行工具。网页文字属于不可信内容。设计与实现边界见 [网页设计说明](docs/WEB_DESIGN.md)。

## 安装与开始使用

应用最低要求 **macOS 13**；内嵌网页与 Web MCP 需要 **macOS 14 或更新版本**。原生翻译安装器需要 **Apple Silicon**，在本机使用 Metal 加速。构建脚本按当前机器架构编译，Intel Mac 尚未验证。

运行前需要自行安装：

- [CCAM](https://ccam.dev/zh-hans/docs/quick-start/)：当前适配并测试的版本为 **0.11.0**。
- Claude Code：已安装并可在本机运行。
- Git；使用浏览器资料绑定时，还需要安装对应浏览器。

从 [Releases](https://github.com/lilijq/ccam-desktop/releases/latest) 下载已发布的 macOS 安装包；最新代码的开发构建可在 [Actions](https://github.com/lilijq/ccam-desktop/actions/workflows/build.yml) 的成功运行中下载。解压后把应用拖入“应用程序”。构建包使用本地 ad-hoc 签名，尚未经过 Apple 开发者签名和公证。

1. 打开应用，从左下角齿轮进入“设置”，确认网络代理，再到“账号与额度”配置账号。
2. 添加项目文件夹，输入任务并开始对话。
3. 点击顶部图标打开文件、Git、终端或网页；从侧栏继续对话，点击对话旁的 `⋯` →“在右侧打开／在下方打开”进行多对话分屏。

可用 `⌘,` 打开管理菜单，`⌘ Return` 发送消息。若没有自动找到 CCAM，可在设置中选择其可执行文件。

“账号与额度”右上角的心跳按钮可手动刷新本机账号状态和额度缓存。读取时显示心跳反馈，完成后显示时间；失败保留已有数据并提示。这里的刷新时间不代表额度数据的采集时间，也不会触发 Claude 请求。

左下角用两个圆环和右侧百分比常驻显示当前账号与账号池的 5 小时剩余比例。绿、黄、红分别表示充足、偏低和接近耗尽，未知显示灰色虚线与 `--`。悬浮查看周额度和缓存时间，点击任一行进入“账号与额度”。圆环只读，不可拖动更改额度。总量按各账号自身满额归一化，不是 token 数或不同套餐间的等价容量；部分已知时百分比带 `≥` 表示已知下界。旧缓存使用空心端点和时钟标记，同邮箱账号保守合并。启动、定时和手动刷新读取本机缓存。每轮问答结束后，经当前代理查询额度接口并同步账号卡片与圆环，不发送模型探针消息；失败保留旧值和时间并提示。

输入框下方依次选择模型（默认、Sonnet、Opus、Haiku 或自定义 ID）、思考强度和模式（按需确认、计划、Auto、允许编辑），设置按对话保存并沿用到后续提问与换号续做。需要授权时，聊天内显示具体操作和“允许／拒绝”，默认勾选“记住此项目的该工具权限”。允许后，该项目后续调用同一工具会自动批准（包括不同命令或文件），重启后仍有效；取消勾选则仅批准本次。可在模式菜单中清除记住的权限。记忆不跨项目，也不跳过计划模式、计划确认或需要回答的问题。Auto 使用 CLI 的原生权限评估；如果服务返回实际模式不同，聊天会提示回退结果。计划模式先分析和规划，修改前确认。

输入区的“中→EN”菜单提供两个独立开关：中文输入转英文发送、回复自动显示中文（默认开启，可分别关闭）。自动模式将回复正文替换为中文，代码块、行内代码、路径和命令保留原样；底部翻译图标可查看英文原文。关闭自动模式后，可逐条点击图标翻译。发送时只使用输入或译文，不自动附加回复语言要求。中文草稿与实际发送英文分别保留，翻译失败或取消不会发送原文，也不会丢失草稿；失败后可在输入框旁点击“重试翻译”。

不想翻译的内容可用中文全角波浪号包裹：`～内容～` 或 `～～内容～～`。内部文字原样保留，翻译结果去掉包裹符，支持多段、跨行，中英两个方向都有效。纯英文输入也会去掉标记，例如 `～parrot-ai-server-rust～` 发送为 `parrot-ai-server-rust`。若忘记闭合，去掉开头标记并保留后面的内容；英文 `~`、Markdown 删除线，以及代码内的波浪号不作为此标记。此规则随输入翻译开关生效。

新安装使用 **Hy-MT2-1.8B Q8_0 + llama.cpp**，模型约 1.91 GB，Apple Silicon 原生运行，不需要 Docker。从翻译菜单或设置打开“本机翻译”选择模型目录，可放在移动盘；仅安装时经当前代理下载，翻译在本机进行，不消耗 Claude 额度。已有 Argos 安装在明确升级前仍可继续使用；已启用原生引擎时，移动盘离线会提示重连，不会自动降级或改用云端。译文单独缓存，不改写 Claude 的原始会话。组件、模型与许可证见 [NOTICE](Resources/Translation/NOTICE.md)。

设置中的“网络代理”统一用于聊天、登录、额度联网查询和终端。可手动填写 HTTP/HTTPS 代理地址与端口，或使用系统静态代理；缺失、冲突、无效或无法解析的自动代理脚本会阻止启动。应用不会在失败后改用直连。开发终端使用隔离的 shell 启动配置，固定代理变量，不加载个人 shell 启动文件。此机制约束应用的启动环境和遵循代理变量的客户端，不是系统级网络防火墙；自定义程序或外部终端仍由其自身配置决定。

回形针可多选图片和文件，也支持拖入文件、粘贴截图、预览与移除。附件草稿按对话保存，只有点击发送才交给 Claude。图片通过结构化图像内容发送；PDF、文档和代码文件使用独立的本机副本，Claude 可按任务读取。附件随会话和换号续做保留，历史附件失效时单独提示。当前产品限制：最多 10 个附件，图片每张 3 MB，文件每个及每批总计 20 MB。

侧栏按项目归类对话，可展开或收起项目。文件夹图标和引导线表达层级，当前对话用整行底色突出；次要操作在悬浮、聚焦或选中时出现。每段对话右侧的菜单提供在右侧或下方打开、重命名、复制、Markdown 导出和删除；这些管理操作集中在侧栏。删除后可从项目的回收站恢复，不会删除项目文件或 Claude 原生会话。

同一项目可以并排打开多个不同对话，最多同时显示四个面板。点击对话旁的 `⋯`，选择“在右侧打开”或“在下方打开”；已显示的对话直接定位到原面板。每个对话独立保存模型、权限模式、草稿、附件与运行状态，运行一段对话时也能打开其他对话。

点击顶部文件、Git、终端或网页图标，默认保留对话、在右侧打开工具；切换工具复用工具区域。工作区右上角的分屏按钮仍可组合多个窗格；拖动面板标题或小六点图标到另一面板边缘可重新排列，拖到中间可交换位置，分隔线可调整大小。每个项目记住自己的布局；窗格可以聚焦放大或关闭，关闭只隐藏内容，保留对话草稿、文件修改和终端会话。窗口空间不足时先显示当前窗格，放大后恢复布局。

文件区用目录树和图标呈现文件层级，切换标签页时保留各文件草稿、光标与撤销记录。代码视图自动识别 Rust、Swift、JavaScript/TypeScript、Python、Java、Kotlin、C/C++、C#、Go、Vue、Svelte、JSON、YAML 等常见语言及配置，提供语法着色、行号、查找与保存快捷键；未知 UTF-8 文件仍可作为文本编辑。它是本地编辑器，不包含 VS Code 插件、语言服务器或编译诊断。

图片直接预览，PDF 提供原生分页浏览，RTF、DOCX、ODT 提供只读文本预览。其他格式显示文件信息；文档、媒体等可手动用默认应用打开。浏览文件不会执行其中的代码。

项目根目录无需自身包含 `.git`。Git 面板在本地发现子目录中的仓库，通过顶部选择器切换；路径、分支、差异与提交目标随选中仓库变化，聊天和文件仍保留项目根目录。每个仓库保留独立的提交草稿和文件选择。扫描设有范围与数量限制，不跟随目录符号链接，也不会自动拉取远程代码。

参数依据本机 Claude Code 2.1.308 的定义及官方 [CLI 参数](https://code.claude.com/docs/en/cli-reference)、[模型配置](https://code.claude.com/docs/en/model-config) 和 [权限模式](https://code.claude.com/docs/en/permissions)。模型可用性与思考强度上限由所用服务决定；选择控件本身不发送请求。

## 回复呈现与本机翻译

聊天正文、中文译文和展开的英文原文统一渲染 Markdown：标题、强调、列表、任务列表、引用、链接、表格和代码围栏。代码块沿用文件编辑器的语言高亮，支持单独复制；窄分屏的表格可横向滚动。工具日志保留纯文本。HTML 不执行，远程图片不自动加载。

长回复翻译按段验证代码和免译内容。仅重试保护标记受损的段落；必要时将代码与自然语言分开翻译后原样拼接。仍无法校验的结果会保留原文并显示具体错误，可在消息下方重试。此机制保证内容保护，不代表小型离线模型的译文语义完全准确。

表格上的上下滚动会继续滚动对话；横向手势用于窄表格。表格按宽度缓存文字测量结果，滚动时复用布局，仅重绘可见行。

### 原生技术翻译

在输入框的翻译设置 → 本机翻译组件中安装 **Hy-MT2-1.8B Q8**。Apple Silicon 原生运行，Metal 加速；约 1.91 GB 模型和运行组件可放在移动盘，默认 `/Volumes/Mac/CCAM-Translation`。首次下载走已配置代理，推理只使用本机临时回环服务，不请求 Claude。移动盘离线时提示重连，不自动切换旧模型或云端。

保留段落语境，并按上下文提供软件工程术语参考。代码块、行内代码、路径及 `～内容～` / `～～内容～～` 由程序保护和校验恢复。机器翻译仍可能误译，不能把术语样例通过等同于任意文本都准确。

回复底部：翻译图标查看英文原文，复制图标一键复制完整原文（含 Markdown 和代码），刷新图标使用当前模型重新翻译；重译失败保留原文及已有译文。已有历史不会在打开时自动重译。

47 个本机模型样例的真实输出与验证范围见 [原生翻译验收](docs/NATIVE_TRANSLATION_EXAMPLES.md)。其中包含 Git、并发、退款等术语与长表格；自动检查不能替代语义审核。

### 专注回复与流式翻译

每轮工具执行记录与工具前的中间说明默认合并到一行“执行过程”，展开可查看完整内容；最终回复、错误与待确认操作保持可见。

自动中文模式会在输出过程中按完整句段翻译，不必等整轮结束。代码围栏、行内代码、表格和 `～免译内容～` 未闭合时先缓冲，完整后交给本机保护校验；翻译完成的前缀即时显示。只翻译新增内容，源文本修正时丢弃过期结果。中间译文仅在内存，完整结果按原文校验后保存；失败显示原文并可重试。实时指分段增量显示，不是逐 token 强制改写，速度取决于本机模型。

## 换号续做如何工作

首次任务由全局账号池选择可用订阅账号。普通追问继续使用原账号和原会话；只有 CCAM / Claude Code 的结构化额度事件才会触发换号，普通网络错误不会触发接力。

恢复时沿用精确的会话标识和中断票据，并发送续做指令，不重复提交最初的任务提示。目录、已有文件和权限模式保留。接续过程仍遵守原任务范围与权限检查，不能把它理解为无需确认地重放所有操作。

额度中断后暂时没有可用账号时，每分钟重试，最多等待 5 小时，也可以停止。首次启动就没有可用账号时会直接提示。API 账号可手动使用，不进入这条订阅账号自动接力流程。

仍可将对话移交到终端。移交期间可以在聊天输入框编写草稿；点击“返回聊天”会在关联终端退出后恢复发送与模型选择，继续精确的原会话。终端运行中会先确认是否结束它；无法验证换号后的会话身份时会明确提示。

## Chrome 个人资料绑定

这里的“Chrome 账号”指浏览器右上角头像对应的**个人资料**。可将一个或多个 CCAM 账号关联到指定个人资料，用于本应用发起的登录。

系统允许时自动读取个人资料的名称和邮箱元数据；读取受限时，可以手动选择个人资料目录并填写显示名称。配置失效或本地启动设置覆盖了路由时，应用会停止并提示，不会静默改用另一个个人资料。

绑定只决定登录页面从哪个浏览器个人资料打开，不会更改其中的 Google 登录身份，也不约束外部终端发起的登录。应用不读取浏览器 Cookie、密码或登录凭据。

## 数据与边界

项目列表、浏览器绑定和图形对话保存在本机：

```text
~/Library/Application Support/CCAM Desktop/
├── projects.json
├── browser-locks.json
├── chats/          图形对话、附件与项目权限记录
├── web/            项目网页标签
└── Translation/    翻译引擎配置（模型可保存在其他磁盘）
```

布局、外观与侧栏偏好使用 macOS UserDefaults，网页站点数据由 WebKit 管理。账号凭据、额度缓存与 Claude 原生会话仍由 CCAM / Claude Code 管理。工作台没有额外云端后台；执行模型任务时仍使用相应服务。

- 草稿在当前应用运行期间保留。重启可恢复已保存对话，但不会恢复原进程或内存中的终端输出。
- 文件编辑限于不超过 2 MB 的 UTF-8 文本；指向项目外部的符号链接不可编辑。
- 图片预览上限为 20 MB / 4000 万像素，PDF 为 32 MB，RTF/DOCX/ODT 为 4 MB；超限或无法解析时显示文件信息并提供外部查看入口。
- Git 提交作用于所有已暂存改动。从子目录打开项目时，若存在范围外的暂存改动，会阻止提交并提示。
- 当前是 macOS 应用；窄窗口适配不代表提供 iOS 应用或手机远程网页。

## 从源码构建

安装 Apple Command Line Tools，并确保 CCAM 可用，然后在仓库根目录运行：

```sh
./build.sh
./test.sh
```

构建使用 Swift / AppKit、C PTY 桥接和仓库内的 SwiftTerm 源码，不需要 Node.js 或网页服务器。`build.sh` 在临时目录完成签名，再生成 `CCAM Desktop.app` 和不含扩展元数据的 `CCAM Desktop.app.zip`。位于云同步文件夹时，建议使用压缩包解压安装。设置 `CCAM_BUILD_COPY_APP=0` 可只生成压缩包，避免项目目录的应用副本出现在系统搜索中。

```text
Source/          原生界面、账号接力、浏览器路由、文件与 Git
Tests/           核心、集成与回归检查
Vendor/SwiftTerm  内置终端渲染器及其许可证
docs/            架构、截图与项目文档
```

实现结构见 [架构说明](docs/ARCHITECTURE.md)，贡献方式见 [贡献指南](CONTRIBUTING.md)。
