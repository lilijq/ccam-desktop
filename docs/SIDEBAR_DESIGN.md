# 项目侧栏与圆环额度

CCAM 是围绕项目进行对话、查看代码和账号接力的本机工作台。侧栏的职责是找到项目与对话，并在不打断工作的情况下知道账号池还剩多少可用额度。

## 视觉方向

沿用用户指定的现代黑。基础色为导航黑 `#080808`、悬浮表面 `#1C1C1C`、选中表面 `#272727`、轨道灰 `#303030`、文字白 `#F5F5F5`、次要灰 `#A3A3A3`。浅色模式使用现有对应主题色。状态色只用于旧缓存等需要注意的信息。

采用 macOS 系统字体：项目名 13px medium、对话 12px regular、导航与轨道标签 11px medium、品牌 15px semibold。中文跟随系统苹方，不引入网页字体。内容左对齐；边距 12px，行高 32px，对话相对项目图标缩进 28px，项目组间距 8px。

```text
  ↻ CCAM
  ✎ 新对话

  项目                         ＋
  ⌄ ▱ parrot-ai                ⋯
       当前对话                ⋯  ← 唯一实心选中背景
       另一个对话              ⋯
  › ▱ ccam-desktop
  › ▱ another-project

  ◔  当前                 76%
  ◔  全部                 41%
  ⚙
```

项目行只用文字和文件夹图标建立层级，当前项目用较亮的字重与图标辨认；对话行才使用选中底色。文件夹图标下的细引导线连接对话，避免对话文字比项目名更靠左。项目的恢复入口与对话操作在整行悬浮、键盘聚焦或选中时显现，保留可访问名称和键盘操作。长名称省略，悬浮显示完整路径或标题。

两行采用圆形 Slider 外观，实际是“查看额度”的按钮，不可拖动修改额度。上方“当前”显示当前账号，下方“全部”显示账号池，圆环右侧显示百分比。统一显示 5 小时剩余比例，周额度独立列在悬浮详情中。大于 50% 为绿、20% 以上至 50% 为黄、20% 及以下为红。未知值用灰色虚线和 `--`；部分已知总量带 `≥` 表示下界。旧缓存保留图形，但用空心端点、时钟标记与悬浮提示说明。每行独立响应点击，进入账号与额度。

## 设计复核

去掉原先的额度数字表格、缓存时间常驻文字和多个同级圆角块；保留“当前 / 全部”两个必要标签，避免两个无文字圆环难以区分。右侧百分比让颜色不是唯一的信息来源。没有把当前项目和当前对话都画成相同的选中卡片。额度的已知、未知和旧缓存通过圆环本身表达，详情留给悬浮与账号页。

验收包括项目折叠与切换、对话操作和恢复入口、滚动时底栏固定、两条额度按钮与键盘聚焦、未知和部分缓存、长标题、深浅色与 640px 高度。使用本机缓存和测试夹具，不发 Claude 请求。
