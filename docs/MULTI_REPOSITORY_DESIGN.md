# 多仓库 Git 与圆环额度

## 产品与视觉方向

一个 CCAM 项目可以是包含多个代码仓库的工作目录。项目保留对话与上下文，Git 面板选择具体仓库执行操作；账号额度仍然属于全局账号池。

保留现代中性黑：导航黑 `#080808`、表面 `#1C1C1C`、文字白 `#F5F5F5`。额度的语义色使用柔和绿 `#82D7B4`、琥珀黄 `#F0BB71`、珊瑚红 `#EF8B85`，灰色沿用现有次要文字与边框色。浅色模式使用更深的对应色以保持可读性。

系统字体承担全部界面角色，仓库名和主操作 13px、路径与额度标签 11px、百分比 13px semibold 并使用等宽数字。内容左对齐，百分比右对齐。保持 4/8/12px 间距与 32px 操作行。

```text
项目 root
  对话 / 文件 / Git / 终端

Git   [ server / api       ⌄ ]   branch       ＋  −  ↻
      改动文件列表                 文件差异
                                  提交说明
                                  状态          提交

  ◔  当前                         76%
  ◔  全部                         41%

```

## Git 行为

- 识别根目录与子目录的仓库，也支持 `.git` 文件形式的工作树。扫描只发生在本地且设定预算，不进入依赖缓存、Git 内部目录或目录符号链接。
- 用相对目录路径区分同名子仓库。切换仓库只改变 Git 面板，不切换项目、对话或文件工作区。
- 保存仓库选择，各仓库的提交草稿和文件选择相互独立；旧异步状态或差异不覆盖新仓库。
- 暂存、取消暂存和提交仅作用于所选仓库。仓库不存在或越出项目边界时阻止操作，写操作进行时禁止切换。
- 扫描未完成与没有找到仓库是不同状态，显示可操作的提示，不自动创建仓库或执行远程拉取。

## 额度圆环

上方当前账号，下方全部账号，延续 5 小时剩余比例。22px 圆环旁保留简短标签，右侧显示百分比；大于 50% 为绿、20–50% 为黄、低于或等于 20% 为红。百分比与圆环同时传达状态，不只依赖颜色。

未知用灰色虚线和 `--`。部分已知的总量以 `≥` 标识已知下界，未知区间为虚线，避免伪装成精确总量。旧缓存用空心端点与悬浮信息说明；不因经过重置时间而自动补满。点击任一行进入账号与额度，悬浮仍单独显示周额度与缓存时间。

## 复核

圆环是本次唯一新增的彩色焦点，其他界面保持安静。Git 不增加装饰性仓库卡片或每个仓库一套按钮；一个明确的选择器同时表达操作范围，保留文件和差异的阅读空间。

离线验收包括多层仓库、工作树、相同文件名隔离、切换草稿、失效仓库、窄分屏、深浅主题、各额度状态和点击入口。真实桌面只查看本地状态，不提交用户仓库、不运行远程 Git 或 Claude 请求。
